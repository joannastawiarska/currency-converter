# Running project

To run this project you have to run following commands:
1. npm install
2. npm run dev

The project should work on localhost:5173

# Documentation

- The "from" field is a numeric input field.
- The "to" field is disabled due to requirements.
- An empty "from" field value is not allowed.
- Conversion occurs when the user types a value in the "from" field or changes the currency.
- Errors are displayed in the console.
